# 决策：唯一可推进所有者

语言：[English](../../decisions/ownership.md) | 简体中文

## 决策与前提

本决策于 2026-10-30 重新设计中采用。`AGENTS.md` 要求 one fact, one owner，以及组合大于继承。早期 API 形状不是兼容约束。结构或生命周期缺陷应修复其所有者，不通过同步规则仲裁竞争副本。

## 直接结果

Scene 成为实际挂载、焦点、事件和语义机制。Base 控制器拥有值和交互事实，kit 填入外观槽并组合真实部件。类型化动作统一可用性与执行。作用域资源区分取消、工作结果和交付。StreamDocument 拥有源修订，Publisher 拥有已接受永久输出。

旧组件适配、独立可写的 accessor 字段值、Markdown 增量永久前缀协议和内联开放行队列被删除。有用保证转为新所有者合同与回归测试保留，旧公开形状不作为兼容包装继续存在。

## 文档与包方向

实际 Go 导入定义架构依赖图。注释可以提及上层消费者，文档可以导航到组合方式。注释提及 `kit` 不等于 core 导入 kit。门禁继续执行真实导入方向、纯渲染、所有者生命周期与 API 迁移证据。

物理文档分为 `core`、`base`、`kit`、`guides` 和 `decisions`，中文页面镜像同一结构。历史报告保留原 API 叙述，并链接到当时修订。它们是既往工作证据，不是当前规范合同。

## 验证与限制

通过公开投影观察事实，并尝试违反边界：绘制中修改、复用卸载 target、接受过时准备、准入超大输出、中止帧，或在物理写入前观察。重构必须保留这些失败保证。性能始终是特定负载下测量得到的属性。
