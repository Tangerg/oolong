# 逻辑文本与单元格投影

语言：[English](../../core/text.md) | 简体中文

## 位置属于文档修订

`text.Position` 表示逻辑行、UTF-8 字节偏移与亲和性，只在某个文档修订内有意义。`text.Layout` 拥有规范化、单元格命中、光标、矩形和渲染行映射。输入是可打印逻辑文本；这里的字节偏移不声称对应原始 Markdown 或终端转义序列。

单元格是显示原子的投影。原子的跨度由 grid 拥有，可以超过两列。裁剪、覆盖、选区修饰与编码保留原子边界。渲染器不能根据字节长度推导宽度，也不能将原子尾部单元格视为独立字符。

## 编辑器与会话组合共享映射

`base.EditSession` 拥有可编辑文本、变更与修订映射。多个编辑器可以查看同一文档，不成为额外文本所有者。选区与光标依据文档变更映射；宽度改变只重建视觉投影。

Transcript 端点额外包含 `BlockID`、准备后的内容修订和逻辑投影指纹。`text.Row.Joined` 与 `Gap` 的软折行元数据用于重建可复制逻辑文本。如果宽度相关渲染器改变了实际复制文本，旧选区将返回 `ErrStaleSelection`；库不会编造并不存在的源映射。

## 阅读与复制

`Transcript.Layout().Hit` 将显示单元格转换为逻辑端点。`Selection.Text(layout)` 从该投影读取可打印文本，`Selection.Rects(layout)` 将高亮投回单元格。选中修订不可用时两者都会拒绝。未知非文本内容保留物理行位置，但不伪造复制文本。

阅读锚点是内容身份、逻辑位置、视口偏移与 scroll 所有者跟随末尾意图的投影。重排据此推导新偏移，锚点不会独立推进滚动状态。固定标题与正文使用同一份候选内容映射。
