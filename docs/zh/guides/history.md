# 保留、发布与虚拟化历史

语言：[English](../../guides/history.md) | 简体中文

## 选择历史生命周期

保留的交互历史属于 Transcript，占用活动 item 预算。不可变捕获接受后，永久终端输出属于 Publisher。持久、可搜索历史属于应用存储。发布到终端 scrollback 不等于创建可随机访问归档，也不能保证终端侧的复制或搜索行为。

应用需要 ID 和回执时可以保留 `TranscriptItem`。退休会清空其正文、文档和订阅。卸载的 scene target 不能作为归档内容地址继续使用，应使用应用内容 ID 与显式归档查询。

## 实例化有界窗口

数据集不适合一次挂载时，使用 `base.VirtualWindow`。实现 `VirtualSource.Revision`、`Len`、`Key` 和纯 `Measure`。Key 表示稳定项目身份，与索引无关。在场景准备前调用 `Resolve(width, height, offset)`；`Build(key)` 只为实例化项目创建实际元素。

默认数据集上限为 100,000 个 key、4 MiB key 字节，每次解析最多进行 512 次测量。只有当前窗口保留测量高度。这些是可调整、会显式拒绝的合同，不保证任意数据集都能容纳。Key 索引和行前缀估算仍随有界数据集规模线性增长。

## 保持身份与如实几何

Key 仍在实例化窗口内时复用同一元素。移除会卸载 target 并撤销绑定其挂载的工作。相同内容 key 之后重新出现，是新的挂载生命周期。无效 key、预算失败、负高度和解析中途源变更，都保留之前窗口。

`VirtualRange.Exact` 表示总高度来自实际测量还是估算。估算几何不能被报告为精确滚动条或权威归档偏移。渲染器能够提供逻辑位置时，应以内容身份与文本位置保存阅读位置。

## 显式表达归档能力

当前库不提供持久归档数据库、通用格式源映射，也不因自动化查询自动实例化屏外内容。应用可以将存储和虚拟窗口操作组合成显式动作。观察应区分不可用、虚拟化与退休内容，不能为它们编造活动 target。
