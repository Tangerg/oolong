Completion has distinct meanings

A successful earlier stage does not claim that later work happened. Source identity, publication responsibility and physical terminal progress keep separate observable outcomes.

  1. Source ended

    EOF creates a final source revision; a preview cannot finalize it.

  2. Preparation accepted

    Identity, revision and finality match the document owner.

  3. Publication accepted

    Immutable content and output responsibility transfer.

  4. Writer admitted

    Exact encoded bytes enter the bounded writer queue.

  5. Bytes written

    The physical watermark settles the publication receipt.
